Claude wrote DX-Ball’s sound rule byte by byte

Does this demo use REA? Only its published findings. The REA team used the tool to inspect the old game and work out how it turned a brick’s position into a number for the sound system. We put that rule in a prompt. Claude wrote two small programs, one for the original rule and one for reversed stereo.

Your browser runs those saved programs locally. You can use this demo without installing REA or connecting to Claude.

Turn Sound on and watch the ball move from left to right. In Original, the beep follows the ball. Switch to Reversed and the beep moves the other way. With sound off, follow the marker below the ball.

What changes when you switch?

The switch selects which WebAssembly program the browser calls for the next sound. Try pressing Pause with the ball near one edge. Switch versions and watch the number change sign. At the right edge, the original program returns 500 (right speaker) and the revised one returns −500 (left speaker). The browser uses the same ball position and the same beep for both.
