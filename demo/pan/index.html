Tap Sound to start the audio. Use headphones to hear left and right: a phone's speakers barely separate them. On an iPhone the page asks Safari for media playback, so the silent switch should not mute it.

Press Pause with the ball near the right edge, then switch between Original and Reversed. At the same position, the answer changes sign: 500 sends the beep right, −500 sends it left.

What changes when you switch?

The switch selects which WebAssembly program the browser calls for the next sound. The browser uses the same ball position and the same beep for both.

Where the two programs came from

REA’s team inspected the old game and published how it turns a brick’s position into a number for its sound system. We used that calculation to write a prompt, and Claude Sonnet wrote two small WebAssembly programs, byte by byte: one for the original rule and one for reversed stereo.

Your browser runs those two saved files locally. You can play this demo without REA, Claude, or the original game. Read the full guide for the prompts, replies, and test results.
